# Are Vision Transformers More Robust Detectors of AI-Generated Images than CNNs?

MAAI901 Deep Learning for Visual Data, Assessment 2: Applied Vision Transformer Report.
University of Wollongong in Dubai.

A pretrained **ResNet-50** (CNN) and **ViT-S/16** (Vision Transformer) of similar size are fine-tuned to tell real photographs from Stable Diffusion images. They are then tested on fakes from newer generators they never saw (SD 2.1 and SD 3.0), on blurred fakes, and on blurred and JPEG-compressed images. The project extends Jiang (2024), whose robustness experiments covered CNNs only.

## Notebooks

| Notebook | What it does | Hardware |
|---|---|---|
| [`01_preprocessing.ipynb`](01_preprocessing.ipynb) | Downloads the datasets, builds class-balanced splits, matches blurred fakes to their originals, removes leaked and duplicate images | CPU |
| [`02_training.ipynb`](02_training.ipynb) | Fine-tunes both models on two training setups with three seeds, plus blur/JPEG-augmented versions (16 runs) | T4 GPU |
| [`03_evaluation.ipynb`](03_evaluation.ipynb) | Accuracy, AUROC, McNemar tests, comparison with Jiang (2024), robustness, Grad-CAM, score distributions, threshold recalibration, per-class results | T4 GPU |
| [`04_demo.ipynb`](04_demo.ipynb) | Interactive Gradio demo: guess real vs fake, newer generators, a blur attack, and Grad-CAM on uploaded images | GPU or CPU |

The notebooks were run in Google Colab, in order, and save everything to `outputs/` in Google Drive. Kaggle access uses a Colab secret named `KAGGLE_API_TOKEN`. Package versions are listed in `requirements.txt`.

## Data

| Dataset (Kaggle) | Fake images generated by | Used for |
|---|---|---|
| [CIFAKE](https://www.kaggle.com/datasets/birdy654/cifake-real-and-ai-generated-synthetic-images) | Stable Diffusion 1.4 | Training setup 1 and testing |
| SD 2.1 CIFAKE 512-32JPG | Stable Diffusion 2.1 | Training setup 2 and testing |
| Stable Diffusion 3.0 CIFAKE, 32x32 JPG (1024) | Stable Diffusion 3.0 | Testing only |
| Gaussian Blurred SD2.1 Images | Stable Diffusion 2.1, blurred | Testing only |

Jiang's datasets are listed on [his Kaggle profile](https://www.kaggle.com/justinjiangnext/datasets). Real images are CIFAR-10 photographs. The datasets and trained models are not stored in this repository because of their size; notebook 01 downloads the data.
